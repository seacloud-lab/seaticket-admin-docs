# Integrations

SeaTicket can connect to third-party services and sync their content into projects. Each integration uses OAuth: register an app with the service provider, then add its credentials to SeaTicket.

| Integration | Description |
| --- | --- |
| [Jira](jira.md) | Sync Jira issues using Atlassian OAuth 2.0 (3LO) |
| [Linear](linear.md) | Sync Linear issues using OAuth 2.0 |
| [GitHub](github.md) | Sync GitHub issues using a GitHub App |
| [Confluence](confluence.md) | Sync Confluence Cloud pages using Atlassian OAuth 2.0 (3LO) |
| [Discord](discord.md) | Sync Discord forum posts using an OAuth2 bot |
| [Gmail](gmail.md) | Connect a personal Gmail mailbox using OAuth 2.0 |
| [Microsoft 365 and Outlook](microsoft-email.md) | Connect a personal Microsoft 365 or Outlook mailbox using OAuth 2.0 |
